# M07：冻结留出日期的 E0/E1/E2 对照

日期：2026-11-11。正式运行 `outputs/ryugu-realism/m07/run-v2/`，run-v1 保留初轮结果。只完成 M07，M08 尚未启动。所有模型、参数、几何、日期划分和掩膜阈值在新测试评价前冻结，本轮没有根据测试结果拟合增益、重选光度规律或调整反照率。

## 结论

在当前 **四日窄相位、已知几何、stride8 点采样、共同训练表面支持** 的条件下，E2 组合管线在四个留出日期上的绝对 I/F RMSE 均低于 E0/E1。按帧再按日期等权汇总，E0/E1/E2 RMSE 分别为 **0.004789 / 0.005447 / 0.003742 I/F**；E2 相对 E0 降低 **21.86%**，相对 E1 降低 **31.31%**。

E1 在四个日期均差于 E0，说明当前未做光度校正的亮度纹理基线没有带来改善。E2 同时改变了光度规律和表面参数，本对照支持这条组合管线，**不能把改善单独归因于反照率估计**，也不证明全局可辨识的真实物理反照率。没有据此声称完整分辨率、大相位、无测试影像辅助的新视角或总体显著性结论。

## 支持、角度与显示诊断

主共同掩膜是冻结几何、有限正观测和三模型有限预测的交集；没有按残差筛选。多日期多帧支持仅作次要子集，测试日其占科学支持约 34.77%–42.99%，不替换主评价。该子集共 170,512 个样点，日期等权 E0/E1/E2 RMSE 为 0.004698 / 0.005059 / 0.003032 I/F。此子集结果不能冒充所有面片已获多日可靠支持；M06 的大日期敏感性仍是限制。

入射/出射固定 15° 分箱，相位固定 1° 分箱，纬度固定南部/中部/北部三个区间。每箱继续按帧和可用日期等权，保留支持帧/日期数和空箱。当前三个纬度区间的 E2 汇总 RMSE 均低于 E0/E1，但不以分组结果重新选择区域或阈值。角度曲线记录全部分箱，窄相位的结果不能支持大相位重照明。

次要 SSIM 先把显示值 clip 到 [0,0.045]，K1=.01、K2=.03，采用 3×3 采样窗口的总体均值/方差/协方差，只有窗口全部共同有效才参与计算。不是默认 11×11 高斯 SSIM，也没有用未知灰色背景制造高分；无窗口时为 null。各日期对有效帧等权，再日期等权，E0/E1/E2 为 **0.466 / 0.409 / 0.618**。科学 MAE/RMSE 不做显示截断。此 SSIM 只描述 stride8 采样上的约 24 原像元窗口，不等同完整分辨率视觉质量。

图组 `heldout-panels.png` 每日期选择按帧 ID 排序的首个共同非空测试帧，不按误差或观感挑图。所有观测/E0/E1/E2使用 I/F 0–0.045，所有残差使用 ±0.015，灰色是共同掩膜之外；原点样本中心 0,8,…,1016，绘图 extent 为 [-4,1020,1020,-4]，共享 crop 250–800 仅用于显示。科学数组仍保存完整 128×128。另有 `error-by-angle.png` 与 `date-rmse.png`；图清单绑定源产品哈希、选择规则、显示范围和全部图片哈希，已人工查看标签与范围。
