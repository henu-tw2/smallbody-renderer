# M05 全局光度与渲染基线设计

沿用已批准总设计和M02四折日期划分，冻结M04几何；本轮不实现M06光度校正反照率。任务代码留在私有适配器，原始影像与核只读。

## 数据流与边界

全部276帧使用stride=8网格，在原始零基像元中心0,8,...,1016发射相机射线，与真实DSK求首交点。缓存plate ID、交点、法向、mu0/mu/相位、遮挡类别；科学预测为128×128采样阵列，附原像元坐标，明确不是像元积分或1024分辨率产品。C++现有UInt16产品仅作历史显示实现依据，不用于拟合。首次实现以SPICE DSK参考求交为准；后续可独立比较加速后端。

太阳由M04的J2000位置和body旋转逆变换，点到太阳/相机单位向量计算cos入射/出射及相位；只在直接受光和可见交点拟合。阴影射线由交点沿外法向偏移0.01m，向太阳投射；保留夜侧/自遮挡/背景。掩膜固定i/e<75°、采样掩膜到最近背景采样中心的EDT>2个网格单元（乘stride为16px尺度）、距影像边缘>=16像元、有限正I/F。所有阈值运行前写protocol.json；不按测试残差调阈值。I/F已SOLDISCR，不再次乘太阳距离平方。

L2a未DISTCR而L2d已DISTCR，不能逐像元套raw饱和掩膜。保守要求整帧raw实测max < DYNRNG-1（无DYNRNG时使用2**BITDEPTH-1），拒绝达到饱和码的帧；保留损失压缩、非线性/杂散光未校正及无法恢复既往削顶的限制。

## 模型

E0：s0*(0.05+0.95*mu0*direct)，均匀表面；保留既有ambient为历史基线。
E1：s1*Araw[plate]*(0.05+0.95*mu0*direct)。仅训练日期直接受光有效像元取每plate I/F中位数，再除以已观测plate中位数固定相对尺度；未知plate保持NaN。它是未经光度校正亮度纹理，不是反照率重建。
LS：sLS*2mu0/(mu0+mu)，零角归一为1，夜侧/阴影直接光为0。
LS–Lambert：a*mu0+b*2mu0/(mu0+mu)，a,b>=0；scale=a+b，LS权重b/(a+b)。相位因子固定1；不拟合Hapke、自由增益或偏置。

参数只用每折两个训练日期，日期等权、日期内帧等权、帧内像元等权的Huber IRLS非负最小二乘，固定Huber尺度0.002 I/F。E0/E1另各拟合单个全局尺度。仅验证日期的逐日期等权RMSE在LS与混合之间选择（相同掩膜）；保存所有候选和矩阵条件数/混合参数相关性。测试日期只导出固定模型预测，M05不读取测试误差选模型。所有四折互不复用拟合状态。

## 交付、隔离与验证

photometry.py定义方向/模型/掩膜/拟合接口，photometry_geometry.py负责DSK采样，photometry_cli.py负责编排；validate_photometry.py独立重放模型/训练来源/几何/掩膜/输出。所有帧留存geometry缓存，四折留存模型、E1表、浮点预测、共同掩膜、训练/验证逐帧指标。测试亮度不进入四折的训练或验证输入；改变某折测试亮度不能改变该折模型。

必须先看到角度定义/阴影/非法值/已知系数恢复/测试泄漏拒绝等失败测试再实现。真实验收要求276帧、四折全覆盖、科学浮点输出、E0/E1与LS类共同几何/尺度/掩膜，保存来源哈希、条件数和局限。不得以正结果作为完成必要条件。

公式依据：[USGS ISIS photemplate](https://isis.astrogeology.usgs.gov/8.1.0/Application/presentation/Tabbed/photemplate/photemplate.html)。LS采用零角归一的2倍形式，尺度由训练拟合。参考[龙宫全局光度研究](https://doi.org/10.1051/0004-6361/201937096)，本实验不估计其完整相位参数。

## 审阅后的边界定义澄清

几何EDT计算于stride8命中掩膜，到最近背景采样中心的距离乘8，不是真实连续轮廓距离的下界。原“距几何轮廓>16原像元”说法过强，现予以撤回。审阅发现首帧(576,320)的缓存距离17.889px通过采样侵蚀，但原像元(572,305)已为背景，距该样点仅15.524px。M05显式接受采样网格侵蚀，不认证真实轮廓16px净距；此次澄清不改变任何掩膜、阈值或拟合结果。证据另存run-v1/sampled-margin-interpretation.json，冻结protocol.json不重写。未来全分辨率实验需重新核验真实轮廓与配准边界。
